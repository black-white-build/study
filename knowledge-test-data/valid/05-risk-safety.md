# 识别关系中的危险信号

以下信号需要高度重视：对方在争吵中摔东西、砸门、损坏财物；威胁伤害你、你的家人或宠物；限制你与朋友家人联系、控制你的经济；反复贬低你并让你相信自己"离了ta就不行"；在情绪激动时推搡、抓拽、掐掐等身体接触；跟踪你的行踪或强行查看你的手机。出现以上任何一种情况，都不应简单归因于"脾气不好"或"一时冲动"，暴力行为具有升级性，第一次出现的容忍会提高后续出现的概率。

# 安全第一：撤离优先于修复

在可能发生人身伤害的关系中，安全永远是第一优先级，沟通技巧和关系修复都必须让位于安全。如果你身处危险环境，不要试图用"好好谈谈"或"再给一次机会"来化解眼前的暴力威胁。优先做三件事：第一，离开危险现场，前往安全的公共空间或亲友住处；第二，将重要证件、钥匙、常用药物放在随时可取的应急包中；第三，告知至少一位信任的人你的处境和去向。

# 求助渠道与自我保护

面对家暴或人身威胁，应当及时寻求官方与专业援助：遭遇正在发生的暴力，立即拨打报警电话；遭受家暴伤害，可拨打当地妇女维权热线求助；紧急情况下可向社区、村委会、居委会或街道司法所求助。注意保留证据：伤情照片、聊天记录中的威胁内容、证人联系方式、报警回执，这些在后续维权中都很重要。不要独自承担或相信"家丑不可外扬"，求助不是羞耻的事。

# 离开危险关系的准备清单

决定离开危险关系时，建议提前准备：规划安全的离开时机和路线；准备好独立的资金账户；备份重要文件与证件；更换常用密码；在安全人员或亲友协助下完成搬离；离开后短期内避免单独与对方见面，必须见面时选择公共场合并有人陪同。离开后如果对方持续纠缠、威胁，不要自行对抗，通过报警和法律途径处理，必要时申请人身安全保护令。请记住，求助渠道和逃生路径永远优先于一切沟通技巧。
