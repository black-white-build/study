# 区分事实与解释

事实是可以被直接观察或核对的事件，例如"对方连续三天没有回复消息"。而"对方故意惩罚我"属于对动机的解释，不能仅凭未回复这一行为确定。讨论关系问题时，先把观察、解释、感受和需要分开，有助于减少误判。练习方法是：描述事件时只用"我看到、我听到、我收到"开头，把"我认为、我觉得他是想"这部分单独标注为猜测，并主动向对方求证，而不是把猜测当成结论。

# 非暴力沟通四要素

非暴力沟通强调四个步骤：观察、感受、需要、请求。观察是不带评判地描述具体行为；感受是表达自己的情绪状态，例如"我感到担心""我感到失落"；需要是说明感受背后的内在需求，例如"我需要被重视""我需要确定感"；请求是提出具体、可行、可协商的行动要求。四个要素连起来可以表达为：我看到你最近很少主动联系，我感到有些失落，因为我需要确定这段关系还在正常发展，你愿意每周固定安排一次通话吗。

# 提出可执行请求

表达需求时，可以描述具体情境、自己的感受和需要，再提出对方能够明确回答的请求。请求应允许对方拒绝或协商；如果不允许拒绝，它更接近要求或控制。可执行的请求具备三个特征：具体（指明时间、地点、方式）、微小（一次只提一件事）、双向（对方可以说"好"也可以说"不好"并给出替代方案）。例如"这周周六晚上八点，我们视频聊半小时好吗"比"你要多陪我"更容易被回应。

# 倾听与确认理解

有效倾听包含三步：放下正在做的事专注对方；不打断、不急着反驳或给建议；用自己的话复述对方的内容并确认，例如"我听到你的意思是……，是这样吗"。确认理解能避免大量误会，尤其是当对方表达情绪时，先回应感受再讨论事情本身。如果发现自己忍不住想反驳，可以先说"我想先确认我理解得对不对"，给自己和对方留出缓冲。
