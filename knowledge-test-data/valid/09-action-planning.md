# 从关系目标到行动步骤

关系改善的目标往往太抽象，例如"想让我们关系更好""想让他更在乎我"，这类目标无法直接执行。行动设计的核心是把抽象目标拆成可观察、可衡量、可执行的具体步骤。以"改善沟通"为例，可以拆为：本周主动发起一次深度对话；每次对话前先说出自己的感受再谈事情；记录一周内使用"你总是"这类绝对化表达的次数并逐周减少。每个步骤都应当足够小，小到当天就能完成并验证。

# 制定行动计划的三要素

一份可执行的行动计划包含三要素：行为、时机、检验标准。行为是具体做什么，例如"每晚睡前问对方今天最开心和最烦心的事"；时机是何时做，例如"晚上九点到十点"；检验标准是做到与否如何判断，例如"一周至少完成五次，完成情况记录在手机备忘录"。计划还应包含应对预案：如果计划执行中断，是调整计划还是调整预期。关系类计划容易因为对方不配合而中断，预案要先区分"对方不支持"和"自己的行动没做到位"。

# 执行中的反馈与调整

计划执行后要定期复盘反馈：每周留十分钟回顾，哪些步骤有效、哪些无效、原因是什么。调整原则是修改步骤而不是放弃目标，例如"主动发起深度对话"效果不好，可以改为"每周六晚饭后一起散步时聊天"，改变触发场景比强迫自己换一种方式硬聊更容易成功。如果连续两周某个步骤都无法执行，说明步骤本身定得太重，应当继续缩小，而不是归咎于自己意志力不足。行动设计的本质是降低开始的门槛，让改变可以从最小动作启动。
