# 非法样本：缺少 front matter 元数据

这份文档故意没有以 --- 开头的 YAML 前置元数据。

使用 rebuildRepository 扫描该文件时，KnowledgeMarkdownParser 会在第一行直接抛出"缺少 Markdown 元数据"异常，因为解析器要求文件必须以 --- 开头。使用手动上传接口上传时则不受影响，因为手动上传只依赖 Tika 抽取正文。这份样本用于验证解析器对文件头格式的强校验。

# 被解析器忽略的内容

如果这份文档真的被当作普通文本上传，正文中的一级标题会被识别为切片章节名，这部分内容用于验证 Tika 抽取与切片章节提取在无元数据场景下的兜底行为。
