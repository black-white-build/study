# HeartPilot 固定对话评测

本目录是对话决策助手的离线固定评测集。`baseline-v0.json` 记录改造前规则在同一批样本上的结果，后续功能必须使用相同样本比较。

指标定义：

- 引用覆盖率：需要知识依据的结论中，带通过校验引用的比例。运行时用引用标记及“研究、数据、通常、表明”等事实性线索做保守计数；离线评测使用样本人工标注。
- 虚假引用率：不存在、证据等级不足或内容不支持的引用数 / 总引用数。
- 无结果降级成功率：没有可用来源时，删除引用并明确说明依据不足的样本比例。
- 高风险召回率：真实或第三方高风险样本进入安全流程的比例。
- 高风险误报率：否定、虚构、假设和普通样本被错误判为安全流程的比例。

运行：`scripts/run-conversation-eval.ps1`。
