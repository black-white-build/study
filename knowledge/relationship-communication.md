# 区分事实与解释

事实是可以被直接观察或核对的事件，例如“对方连续三天没有回复消息”。“对方故意惩罚我”属于对动机的解释，不能仅凭未回复这一行为确定。讨论关系问题时，先把观察、解释、感受和需要分开，有助于减少误判。

# 提出可执行请求

表达需求时，可以描述具体情境、自己的感受和需要，再提出对方能够明确回答的请求。请求应允许对方拒绝或协商；如果不允许拒绝，它更接近要求或控制。

# 比较方案与风险

关系决策通常没有单一正确答案。可以同时比较立即沟通、暂时冷静、设置边界和结束接触等方案，并说明每种方案的适用条件、短期成本和潜在风险。涉及现实人身危险时，应优先离开危险环境并寻求当地紧急或专业援助，而不是继续尝试沟通技巧。
